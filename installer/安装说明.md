# 话术润色助手 · 安装说明

在微信里打字时，按一个快捷键，AI 帮你把话术润色成几个版本（或帮你起草回复），选一个自动填回微信输入框。

**不需要你预先安装 Python**——运行环境已经打包在 App 里面了。

---

## 〇、先确认这台 Mac 能不能装

| 项目 | 要求 |
|---|---|
| **芯片** | **Apple Silicon（M1 / M2 / M3 / M4 系列）** —— **Intel 芯片的 Mac 装不了** |
| **系统** | macOS **13.0** 或更高 |
| 其它 | 不需要预装 Python；运行环境已打包在 App 内 |

怎么看芯片：点左上角  →「**关于本机**」，看「**芯片**」那一栏写的是
`Apple M…` 还是 `Intel…`。

> 安装脚本会自动做这项检查，芯片不匹配会直接明确告诉你（不会装到一半才失败）。
> 当前这份安装包只包含 Apple Silicon 版本；如果你的 Mac 是 Intel，需要另出一版。

---

## 一、安装（两种方式，任选一种）

### 方式 A：双击安装（推荐）

1. 双击 **`安装 话术润色助手.command`**
2. 如果系统提示「无法打开，因为它来自身份不明的开发者」：
   在文件上**点右键 →「打开」**，然后在弹窗里再点一次「打开」。
   （只需做这一次，之后就不会再问了）
3. 按终端窗口里的提示走即可，它会自动：
   - 把 App 装到「应用程序」
   - 解除系统的隔离标记（不做这一步，之后每次打开都会被拦）
   - 校验签名，并告诉你接下来要授权什么

### 方式 B：手动拖拽

把 **`话术润色助手.app`** 拖到右边的 **`应用程序`** 上。

> 拖拽方式**不会**解除隔离标记，第一次打开时需要在 App 上**点右键 →「打开」**，
> 弹窗里再点一次「打开」。之后就能正常双击了。

## 二、第一次打开：两步必须做的事

程序启动后，屏幕**右下角会出现一个小图标**，那是它的主要入口
（Dock 里也会有一个图标，方便你看到它在运行）。

### 第 1 步：给它两项系统权限

macOS 会拦截截图与按键模拟，所以必须手动授权。程序会弹出「**还差一步授权**」窗口，
按上面的「去授权」按钮即可跳到对应的系统设置页面。

| 权限 | 用来做什么 | 生效时机 |
|---|---|---|
| **辅助功能** | 读输入框草稿、回填、全局热键 | 打开开关后**立即生效** |
| **屏幕录制** | 截图读取聊天上下文 | 打开开关后**需要退出重开 App** |

> **两个最容易卡住的地方：**
>
> 1. **系统设置列表里，本程序叫 `话术润色助手`**（App 的文件名），
>    不是界面上的中文名「话术润色助手」——照中文名去找是找不到的。
> 2. **「去授权」不等于已授权**：它只是帮你跳到设置页，跳过去之后
>    还要自己把那一行**最右侧的开关拨开**。
>
> 授权后回到那个窗口点「重新检测」，会显示 ✅ 已授权。

### 第 2 步：填你自己的 API Key

接着会弹出配置窗口，把你自己的 DeepSeek API Key 粘贴进去，点「测试连接」确认可用，
再点「保存并启动」。

申请地址：<https://platform.deepseek.com/api_keys>（新用户有免费额度，日常聊天基本够用）

## 三、日常使用

1. 打开**微信 Mac 版**并登录，进入要回复的聊天窗口
2. 在输入框里打几个字（哪怕只写关键词）
3. 按 **`Ctrl + Alt + P`**（或点一下右下角的小图标）
4. 稍等 1~2 秒，弹出窗口里会有 3 个版本
5. 点「**发送**」→ 自动填回微信输入框（你再按微信的发送键）；点「**复制**」则只复制

**打开设置页**：右键点击右下角小图标 →「打开设置…」
（里面可以改提示词风格、管理多套模型与 Key、看使用说明）

**退出程序**：鼠标移到右下角小图标上，点右上角浮现的 **×**；或右键 →「退出」

## 四、卸载

双击 **`卸载 话术润色助手.command`**，按提示操作即可。

它默认只删程序本体，会问你「要不要连配置与日志一起删」。
另外还需要你手动到「系统设置 › 隐私与安全性」把本程序从权限列表里移除（系统不允许脚本代劳）。

## 五、常见问题

**Q：双击 App 提示「无法打开，因为 Apple 无法检查它是否包含恶意软件」？**
- 这是因为程序没有苹果的付费开发者签名（个人作品常见情况），不是有毒。
- 解决：在 App 上**点右键 →「打开」**，再点一次「打开」。之后就能正常双击了。
- 或者用「方式 A」的安装脚本，它会自动解除隔离标记。

**Q：按热键没反应？**
- 先确认「辅助功能」已授权（设置页里能看到状态）
- `Ctrl + Alt + P` 里的 Option+P 在部分输入法下会打出 π 造成冲突；
  这时可以把 `hotkey` 改成 `f8`（在「设置」里改，或改配置文件里的 `hotkey` 字段）

**Q：读不到聊天内容 / 上下文是空的？**
- 确认「屏幕录制」已授权，并且**授权后退出重开过 App**
- 确认微信窗口没有被最小化

**Q：想看看它到底发了什么给 AI？**
- 日志在：`~/Library/Logs/话术润色助手/polish.log`
  （在 Finder 里按 `⌘⇧G`，粘贴这个路径即可）
- 日志是**加密保存**的，直接打开是密文（每行以 `WPENC1:` 开头），这是正常现象。
  需要看明文时：在程序目录执行 `python3 log_decrypt.py` 会还原出一份副本。

**Q：配置和日志存在哪？**
- 配置：`~/Library/Application Support/话术润色助手/config.json`（**含明文 API Key**，别发给别人）
- 日志：`~/Library/Logs/话术润色助手/polish.log`

## 六、卸载不完全 / 想彻底清理

手动删掉这三个即可：

```
/Applications/话术润色助手.app
~/Library/Application Support/话术润色助手
~/Library/Logs/话术润色助手
```

再到「系统设置 › 隐私与安全性」把本程序从「辅助功能」「录屏与系统录音」里移除。
